# ASP.NET Online Library Management System

## Overview

The Online Library Management System is a web-based application developed to automate and simplify library operations. The system provides separate dashboards for administrators and students, enabling efficient management of books, users, and circulation activities.

## Features

### User Authentication
- Secure login and logout functionality
- Role-based access control
- Separate access for Admin and Student users

### Book Management
- Add new books
- Update book details
- Delete books
- Manage book inventory

### Book Issue & Return
- Issue books to students
- Return books management
- Track issued books
- Monitor due dates

### Search Functionality
- Search books by title
- Search by author
- Search by category
- Quick and responsive search results

### Admin Dashboard
- Manage students
- Manage books
- View issued books
- Monitor return status
- Dashboard statistics and reports

### Student Dashboard
- View available books
- Search books
- View issued books
- Track return dates
- Manage personal profile

### Real-Time Features
- Real-time notifications using SignalR
- Instant updates for library activities

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Rehman481/Asp.net-Library-Management-System.git
```

2. Open the solution in Visual Studio.

3. Configure the SQL Server connection string in `appsettings.json` or `Web.config`.

4. Restore NuGet packages.

5. Run database scripts.

6. Build and run the application.
